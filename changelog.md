# Lettuce's Balanced Crates Changelog (NeoForge 1.21.1)
## Update 2.0.1

## Update 2.0 
### Changes
- Balanced Crates has been remade from scratch, and is no longer made in McCreator
- Balanced Crates has been renamed to Lettuce's Balanced Crates to be more consistent with my other mods.
- Crates now have their own seperate creative tab.
- Crates will appear after barrels in the Function Blocks creative tab
- Added the following translations:
  - Spanish 
  - French 
  - German 
  - Russian
  - Korean
- Crate block type has been reworked into one class, that way adding crates in the future will be much easier and more streamlined.
- Crates now have custom place and break sounds that match their respective wood type.
- Crate map colors are now accurate.
- Crate opening/closing sounds have been pitched down

### Bug Fixes

- All blocks are now the crate block type, instead of having separate block type
- Crates will no longer make multiple sounds when opended or closed
- Crate subtitles no longer say barrel open/close
